# Beef Burger Patties — Pakistan's Premium Craft Burgers

A production-grade, full-stack craft burger restaurant web platform built with:
- **Frontend**: React 19 + TypeScript + Vite 8
- **Styling**: Tailwind CSS v4 + Custom Dark Noir Design System
- **Animation**: Framer Motion + Cinematic Video Hero
- **Backend & Database**: Supabase PostgreSQL (15 operational tables)
- **Authentication**: Supabase Auth
- **Realtime**: Supabase Realtime Channels for Live Order Dispatch Tracking
- **Icons**: Lucide React

## Features
- Real relational database ordering pipeline (`orders`, `order_items`, `order_status_history`)
- Live order tracking radar with real-time status progression
- Full product customizer with live price calculation in PKR (`Rs.`)
- Live Kitchen Operations Admin Dashboard (`/admin`)
- Multi-city delivery selector (Islamabad, Rawalpindi, Lahore, Karachi)
- VIP Flavor Dispatch newsletter subscription
- Interactive customer review submission directly into PostgreSQL
